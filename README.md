# 2N share 

This is a fully functional python base application. This is a simple altanative application same to Shareit. 

## Why this is better than shareit

1. This is very light and simple
2. No need to get any applcation for mobile
3. Mobile OS is not relavant to use (IOS user can simply use this to share their files with their windows Pcs)

## How use this (Developers)
- If you need to do development, the finals are in main file please clone it.
